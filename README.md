# AI Doctor X — fork and project notes

This is a personal fork of [Soujanya-cse/AI-Doctor-X](https://github.com/Soujanya-cse/AI-Doctor-X). See the upstream repository for the original project and its history.

The repository contains a web application codebase (`src/`, `server/`, `shared/`, and `index.html`). The earlier README described AI disease prediction, augmented reality, 3D simulations, and treatment guidance, but those capabilities have not been verified against the current code in this fork. This README does not claim they are implemented or validated.

## Safety

This is an educational code repository, not a medical product. It must not be used to diagnose, predict, or guide treatment. No clinical validation or patient-data protections are claimed.

## Contribution scope

This repository is a fork. Review the commit history and source files to distinguish upstream work from changes made in this copy. No individual feature ownership is claimed here.
